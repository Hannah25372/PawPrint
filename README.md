Welcome to PawPrint

Features
- Dog walk paths
  - Record walked paths
  - Record metadata such as elevation...

- Account system
  - Profiles
    - username, bio, dogs (name, breed, age, temperament, pic), profile pics
    - display walked paths on profile (granular access e.g. followers, publicly)
  - Following/Followers
    - customised feed based on following
  - Groups

Extras
- Ability to advertise "job" to walk dog (borrow my doggy)
